# ZweiCheck – Nutzerflüsse

## 1. Erststart und Kontoerstellung

### Ziel

Der Nutzer versteht innerhalb weniger Sekunden, was ZweiCheck tut, und verbindet möglichst früh eine Vertrauensperson.

### Ablauf

1. Begrüßungsbildschirm mit Logo und Claim.
2. Erklärung in einem Satz:
   - „Unsicher? Lass kurz jemanden mit draufschauen.“
3. Konto erstellen mit E-Mail oder später Apple/Google.
4. Vorname eingeben.
5. Vertrauensperson einladen.
6. Einladung per Link oder Code teilen.
7. Nach Annahme erscheint die gemeinsame Verbindung.

### Regel

Die App darf den Nutzer nicht mit Profilfeldern, Einstellungen oder langen Erklärungen aufhalten.

---

## 2. Prüfung anfordern

### Startseite

Die zentrale Aktion lautet:

> **Prüfung starten**

Darunter erscheinen nur:

- offene Prüfungen
- Vertrauenskreis
- Verlauf

### Ablauf

1. Nutzer tippt auf „Prüfung starten“.
2. Kategorie wählen:
   - Nachricht oder Anruf
   - Zahlung oder Rechnung
   - Link, QR-Code oder App
   - Daten oder Dokumente
3. Kurz beschreiben, was verlangt wird.
4. Optional hinzufügen:
   - Screenshot oder Foto
   - Text
   - Sprachnachricht
   - Betrag
   - angegebener Zeitdruck
5. Vertrauensperson oder gesamten Vertrauenskreis wählen.
6. Sicherheits-Hinweis bestätigen:
   - „Bis zur Rückmeldung noch nichts bezahlen, installieren oder weitergeben.“
7. Anfrage absenden.
8. Statusseite zeigt:
   - gesendet
   - gesehen
   - Rückmeldung erhalten

### Pflichtfelder

- Kategorie
- kurze Beschreibung
- mindestens eine Vertrauensperson

### Keine Pflichtfelder

- Betrag
- Anhang
- Zeitdruck

---

## 3. Ansicht der Vertrauensperson

### Benachrichtigung

Beispiel:

> „Mama bittet dich um einen ZweiCheck: Zahlung oder Rechnung.“

Keine sensiblen Details im Sperrbildschirm anzeigen.

### Ablauf

1. Vertrauensperson öffnet die Anfrage.
2. Sie sieht:
   - Absender
   - Kategorie
   - Beschreibung
   - Betrag und Zeitdruck
   - Anhänge
   - Zeitpunkt
3. Sie kann direkt anrufen.
4. Sie wählt eine Empfehlung:
   - Nicht handeln
   - Erst persönlich klären
   - Wirkt nachvollziehbar
   - Ruf mich jetzt an
5. Optional kurze Begründung hinzufügen.
6. Rückmeldung absenden.

### Sicherheitsregel

„Wirkt nachvollziehbar“ muss einen Hinweis enthalten:

> „Das ist eine persönliche Einschätzung und keine Garantie.“

---

## 4. Rückmeldung empfangen

1. Geschützte Person erhält eine Benachrichtigung.
2. Ergebnis wird groß und eindeutig dargestellt.
3. Kurze Begründung steht direkt darunter.
4. Hauptaktionen hängen von der Empfehlung ab:
   - Anrufen
   - Bekannte Nummer selbst wählen
   - Vorgang schließen
   - weitere Person fragen
5. Die Person bestätigt abschließend:
   - „Ich habe noch nicht gehandelt“
   - „Ich habe persönlich geklärt“
   - „Vorgang erledigt“

Die App soll niemals automatisch behaupten, eine Zahlung oder Handlung sei sicher.

---

## 5. Vertrauenskreis

### Verbindung herstellen

1. Nutzer tippt auf „Person hinzufügen“.
2. Rolle beziehungsweise Beziehung optional wählen.
3. Einladungslink oder sechsstelligen Code erstellen.
4. Empfänger akzeptiert die Verbindung.
5. Beide sehen klar, welche Informationen geteilt werden können.

### Berechtigungen

Pro Verbindung einstellbar:

- darf Prüfungen empfangen
- darf als Prioritätskontakt gewählt werden
- darf weitere Familienmitglieder einladen
- darf den gemeinsamen Verlauf sehen

Standardmäßig sieht eine Person nur Vorgänge, an denen sie beteiligt ist.

---

## 6. Familiencode

### Zweck

Ein gemeinsames Codewort hilft bei angeblichen Notfällen oder gefälschten Familiennachrichten.

### Ablauf

1. Familie legt gemeinsam ein Codewort fest.
2. Codewort wird verschlüsselt gespeichert.
3. In einer verdächtigen Situation kann eine Person die Prüfung „Familiencode abfragen“ starten.
4. Die App zeigt nie das Codewort in einer normalen Benachrichtigung.
5. Änderungen werden allen berechtigten Personen angezeigt.

---

## 7. Verlauf

Der Verlauf ist keine Statistikseite, sondern eine einfache Liste abgeschlossener und offener Vorgänge.

Jeder Eintrag zeigt:

- Kategorie
- Datum
- beteiligte Personen
- Empfehlung
- Abschlussstatus

Filter im MVP:

- offen
- abgeschlossen
- von mir angefragt
- von mir geprüft

---

## 8. Abo-Abschluss

Das Familienabo wird nicht beim ersten Öffnen aggressiv angeboten.

Gute Zeitpunkte:

- wenn das kostenlose Monatslimit erreicht ist
- wenn eine dritte Person eingeladen wird
- wenn mehrere Vertrauenspersonen gewünscht werden
- nach einer erfolgreich abgeschlossenen Prüfung

Die Bezahlseite erklärt zuerst den Familiennutzen und erst danach den Preis.

---

## 9. Fehler- und Ausnahmesituationen

### Keine Vertrauensperson reagiert

- Erinnerung nach einstellbarer Zeit
- Anfrage an weitere Vertrauensperson weiterleiten
- Hinweis: bekannte offizielle Nummer selbst zurückrufen

### Keine Internetverbindung

- Entwurf lokal speichern
- klar anzeigen, dass noch nichts versendet wurde
- automatischer Versand erst nach erneuter Bestätigung

### Unmittelbare Gefahr

Bei Hinweisen auf akute Bedrohung, Gewalt oder medizinischen Notfall verweist die App klar auf lokale Notruf- und Hilfsangebote. ZweiCheck ersetzt keinen Notruf.
